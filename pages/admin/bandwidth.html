ℹ️ "Today's Usage" and "Range Total" cover HTTP routes this server handles — both the request-body bytes it receives (uploads, e.g. the VBA sync tool's bulk row uploads, shown as separate IN <route> rows below) and the response bytes it sends back — plus outbound calls it makes via fetch() (GitHub, Render's own API, etc.). For the wide bulk row-fetching endpoints (ArreasT24ByCO, NBC Overdue, the main OS/CreditMonitoring grid, Debit Turn Over, etc.) they also include an approximate size of what each query pulled from MongoDB Atlas, shown as separate DB <route> rows below — approximate because it's measured from the JSON size of the fields actually returned, not a true wire-byte count.
