Root Cause (documented reasons)

    How these figures are calculated
    • Opening — NPL loans (Sub-Standard, Doubtful, Loss) saved on the last day before From.
    • Closing — today's NBC Overdue NPL loans (or the day saved at To).
    • New = only in Closing · Recovered = only in Opening · Continuing = in both. Each loan is compared once, so one that changed class several times is counted once.
    • Closing = Opening + New − Recovered + Balance changes.
    • With an NPL class picked, opening and closing are that class's own balances; a loan that moves between NPL classes enters or leaves the class (shown as "moved to another NPL class").
    • NPL_Area and NPL_Own both come from NBC Overdue (3 classes: Sub-Standard, Doubtful, Loss): Own = loans under the CO's officer ID (column AJ, default); Area = loans whose CO Response name (column CE) is the officer, like the Daily Report.
    • Reasons are only those officers documented in Reason Arrear — none is guessed.

    Recovery Performance

    What reduced NPL — kept apart

    A fall in NPL is not cash: only collections on written-off loans are cash figures in CM Pro.

    Recovery by

    Monthly NPL recovery targets (admin)
    How these figures are calculated
    • Recovered = opening balance of NPL loans that left NPL by being upgraded, becoming performing or closing. Write-offs are counted separately, not as recovery.
    • Recovery rate = Recovered ÷ Opening NPL. Net NPL movement = Closing − Opening NPL.
    • Cash collected exists only for written-off loans (WO collections in the period). Cash paid on NPL loans has no data source, so it is shown as not available.
    • Target achievement = Recovered ÷ the monthly targets an admin set for the branches and months in the period.
